RUN HARNESS AGENTS ON THE CLUSTER YOU ALREADY PAY FOR.

Harness agents are not stateless microservices. Kubernetes glued identity, resources, and lifecycle to the pod. Agent Substrate is how kagent runs that class on Kubernetes you already have — actor off the pod, warm workers, checkpoint when idle — instead of a cloud agent PaaS.
