The shift

Kubernetes was designed for long-lived stateless services. A harness agent is bursty, stateful, and idle most of the time. If each session owns a pod, you pay for the empty room.

Harness agent

Why teams buy a PaaS

AWS Bedrock AgentCore and Google Gemini Enterprise Agent Platform (formerly Vertex AI Agent Builder) exist because platform teams do not want to host this class of workload themselves.

Idle capacity already paid for

Cast AI 2026 report: average CPU utilization ~8% in 2025; CPU overprovisioning ~69%. Cast AI sells optimization software — disclose that. Direction matches other cluster-waste studies.

Accurate frame: marginal compute on capacity you already own can be near zero. Substrate itself, GPU node pools, and ops are still real costs.
